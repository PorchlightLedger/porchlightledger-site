# porchlightledger.com

Static site for the Porchlight Ledger Etsy shop. Plain HTML/CSS, hosted on GitHub Pages (custom domain via `CNAME`).

- Edit products/prices in `src/build.py`, page copy in `src/index.template.html`, then run `python3 src/build.py` to regenerate `index.html`.
- Free worksheet signup posts to Kit form 9997857 (landing page: https://porchlight-ledger.kit.com/16208810d1).
